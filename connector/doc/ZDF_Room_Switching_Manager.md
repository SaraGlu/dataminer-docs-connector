# ZDF Room Switching Manager

## About

The ZDF Room Switching Manager coordinates switching workflows between active and passive broadcast rooms. It runs configured steps across both rooms and tracks their progress, helping operators manage a room switch from DataMiner.

## Key Features

- **Coordinated switching**: Execute switching steps across the active and passive rooms.
- **Multiple modes**: Run Maintenance, Force, or BaseConfig workflows.
- **Progress visibility**: Follow sequence state and step results in DataMiner.
